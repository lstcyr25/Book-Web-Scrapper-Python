# Book Web Scraper (Python)

## 📊 Overview

This project automates the process of extracting book data from a website using Python.

The scraper collects information such as book titles, prices, and ratings, and stores the data in a structured format for analysis.

---

## 🎯 Objectives

* Extract data from a website using web scraping techniques
* Parse HTML content to retrieve relevant information
* Store data in a structured format (CSV)
* Automate data collection for future analysis

---

## 🛠️ Tools & Technologies

* Python
* Requests (HTTP requests)
* BeautifulSoup (HTML parsing)
* Pandas (data storage and manipulation)

---

## 📁 Dataset

* Source: books.toscrape.com
* Data collected includes:

  * Book titles
  * Prices
  * Ratings
  * Availability

---

## 🔍 Process

### 1. Send HTTP Request

* Retrieved webpage content using Python requests library

### 2. Parse HTML

* Used BeautifulSoup to navigate and extract relevant elements

### 3. Extract Data

* Collected book information such as title, price, and rating

### 4. Store Data

* Saved extracted data into a CSV file for further use

---

## 📊 Output

* Structured dataset containing scraped book information
* Ready for further analysis or visualization
